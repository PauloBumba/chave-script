Estúdio da Vilaao vivo




programa    ::= VILA COMECA conversa* VILA TERMINA
conversa    ::= CONVERSA ENTRE personagem (E personagem)+
elenco      ::= 2 a 6 personagens, sem repetição
                ( ASSUNTO expr | ESTILO estilo | comando )*
                CENA TERMINA
comando     ::= personagem ENTRA | personagem SAI
              | personagem (DIZ|RESPONDE|PENSA|GRITA) expr
              | personagem PERGUNTA expr EM variavel
              | declaracao | repeticao | condicao
personagem  ::= CHAVES | SEU_MADRUGA | QUICO | CHIQUINHA | PROFESSOR_GIRAFALES | SR_BARRIGA
estilo      ::= ENGRACADO | EDUCATIVO | DRAMATICO

expr        ::= termo (('+'|'-') termo)*        // + também concatena TEXTO
termo       ::= fator (('*'|'/') fator)*
fator       ::= '-' fator | primario
primario    ::= NUMERO | TEXTO | variavel | '(' expr ')'

declaracao  ::= (TEXTO | NUMERO) nome = expr
repeticao   ::= REPETE expr VEZES comando* FIM
condicao    ::= SE expr (IGUAL|DIFERENTE|MAIOR|MENOR) expr comando*
                [ SENAO comando* ] FIMSE

Sem comandos de fala, o motor gera o diálogo.
Comentários: // até o fim da linha.
Acentos são opcionais (COMEÇA = COMECA).
Atenção: // sempre inicia comentário; use espaços em divisões
ex.: NUMERO x = 10 / 2  (e não 10//2).


1. Estrutura
Todo programa abre com VILA COMEÇA e fecha com VILA TERMINA. Dentro dele ficam uma ou mais conversas.
2. Conversa automática
Diga quem conversa, o assunto e o estilo. O motor escreve as falas.
CONVERSA ENTRE QUICO E CHIQUINHA
  ASSUNTO "futebol"
  ESTILO DRAMÁTICO
CENA TERMINA
3. Falas escritas por você
Use ENTRA, DIZ, RESPONDE, PENSA, GRITA e SAI. Só os personagens da conversa podem falar (2 ou mais, ex.: CONVERSA ENTRE CHAVES E CHIQUINHA E QUICO).
CHAVES DIZ "Oi!"
QUICO RESPONDE "Oi."
4. Painel de configuração
Troca personagens, assunto, estilo, velocidade e cenário na hora de executar, sem alterar o código. Em falas escritas por você, o painel só troca quem fala; o texto continua o seu.
5. Variáveis, contas e condições
Declare com TEXTO ou NUMERO. Use + - * / e parênteses nas expressões (+ também junta textos) e decida com SE ... SENÃO ... FIMSE usando IGUAL, DIFERENTE, MAIOR ou MENOR. O compilador confere os tipos.
TEXTO oi = "Olá!"
NUMERO n = 3
NUMERO dobro = n * 2 + 1
CHAVES DIZ oi
SE dobro MAIOR 2
  QUICO PENSA "Muita coisa..."
SENÃO
  QUICO PENSA "Pouca coisa."
FIMSE
6. Entrada de dados (PERGUNTA)
O personagem pergunta algo e a resposta digitada no estúdio é guardada na variável declarada antes. Se for NUMERO, o compilador exige um número.
NUMERO idade
CHAVES PERGUNTA "Quantos anos o senhor tem?" EM idade
SE idade MAIOR 17
  CHAVES DIZ "Pode entrar!"
SENÃO
  CHAVES DIZ "Volta pra escola!"
FIMSE
7. Gerar JavaScript
O botão “Gerar JavaScript” traduz o programa para Node.js (aba JS). O código gerado usa console.log para as falas e lê as respostas do PERGUNTA pela entrada padrão: rode com node programa.js < respostas.txt.
8. Erros comuns
Personagem inexistente (CHAVES2), faltou CENA TERMINA, aspas sem fechar, variável não declarada, tipo errado numa conta ou código depois de VILA TERMINA. O console mostra a linha.




Código JavaScript geradocopie ou baixe e execute com Node.js
Como executar
O código gerado lê as respostas do PERGUNTA pela entrada padrão. Use um arquivo de entrada ou pipe:
node programa.js < respostas.txt
ou cole as respostas e pressione Ctrl+D no terminal.
